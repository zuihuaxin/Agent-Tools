名称：清盘侠 · DiskHero，副标题「专治 C 盘爆满」

定位：面向不懂电脑、看到 C 盘飘红就慌的人；也面向装了 Claude Code、Cursor、WorkBuddy、Ollama 等工具、C 盘被日志和模型悄悄占满的人。

五个功能（截图都是真实运行的输出，不是合成图）：

[1] 体检：排列 C 盘占用，AI 工具用黄色标出，只读并提供 CSV
[2] 快清：缓存、日志、临时文件，实测 18.03 GB / 30 处
[3] 深清：旧版本程序、插件池、更新包残留
[4] 搬家：把日志搬到大盘并建目录联接，治本（自动挑选剩余空间最大的固定盘，不写死 D 盘）
[5] 还原：后悔药，按记录搬回
